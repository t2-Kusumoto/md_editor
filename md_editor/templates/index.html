Keyboard Shortcuts

Edit Mode - Typing inside a cell

  • Esc Switch to Command mode
  • Ctrl + Enter Render cell and stay on current cell
  • Shift + Enter Render cell and select below (or create new at end)
  • Ctrl + / Toggle comment for selected lines or current line
  • Ctrl + Alt + - Split cell at selection or midpoint
  • Ctrl + Shift + K Delete current line(s)
  • Ctrl + Shift + D Duplicate current line(s) downward
  • Ctrl + Shift + ↑ / ↓ Move line(s) up or down within cell
  • Ctrl + B Bold text (**bold**)
  • Ctrl + I Italicize text (*italic*)
  • Ctrl + ← / → Move cursor to start / end of current line
  • Ctrl + ↑ / ↓ Move cursor to start / end of cell
  • Ctrl + H Open in-cell string replacement prompt (Replace)
  • Ctrl + G Open in-cell line jump prompt (Go to Line)
  • Ctrl + Alt + L Recenter current line 12 lines below header

Command Mode - Cell navigation & manipulation

  • Enter Enter Edit mode for selected cell
  • J or Ctrl + ↓ Select cell below
  • K or Ctrl + ↑ Select cell above
  • ↑ / ↓ Smoothly scroll viewport up or down
  • H or ← Move focus to left pane
  • L or → Move focus to right pane
  • Ctrl + Shift + ↑ / ↓ Move selected cell(s) up or down
  • A Insert new cell above
  • B Insert new cell below
  • D, D (press D twice) Delete selected cell(s)
  • C Copy selected cell(s)
  • X Cut selected cell(s)
  • V Paste cell(s) below
  • Shift + V Paste cell(s) above
  • Shift + ↑ / ↓ / J / K Multi-select adjacent cells
  • Shift + Click Range-select cells
  • Esc Clear multi-selection back to single cell
  • Shift + M Merge all selected cells
  • Ctrl + Alt + - Split selected cell into two
  • Z / Ctrl + Z Undo cell operation
  • Shift + Z / Ctrl + Y Redo cell operation
  • Ctrl + A Select all cells
  • Ctrl + Alt + L Recenter active cell 2 lines below header
  • G, G Jump to first cell
  • [Number] + G, G Jump to cell number (e.g. 5gg)
  • Shift + G Jump to last cell
  • Shift + Enter Render cell (preview)
  • Ctrl + \ Split editor vertically (up to 3 panes)

Global Shortcuts

  • Ctrl + Shift + ← / H Switch to tab on the left
  • Ctrl + Shift + → / L Switch to tab on the right
  • Ctrl + N / Ctrl + Alt + N Create new notebook (new tab)
  • Ctrl + Alt + W Close active tab
  • Ctrl + Alt + M Merge current pane into left pane
  • Ctrl + S Save notebook
  • Ctrl + Alt + S Save notebook as new file (Save As)
  • Ctrl + \ Split editor vertically (up to 3 panes)
  • Ctrl + Shift + F Toggle File Browser sidebar
  • Ctrl + Alt + F Toggle Table of Contents sidebar
  • Ctrl + Shift + Q Quit application and stop server

File Browser (When not editing cells)

  • Ctrl + C Copy selected file / folder
  • Ctrl + X Cut selected file / folder
  • Ctrl + V Paste copied / cut file or folder
