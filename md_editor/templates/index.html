Jupyter Lab Keyboard Shortcuts

Edit Mode (編集モード) - セル入力中

  • Esc Commandモードへ移行
  • Ctrl + Enter セルを実行し、Commandモードへ移行
  • Shift + Enter セルを実行（プレビュー）し、下のセルを選択（無ければ新規作成）
  • Ctrl + / 選択範囲 / 現在行をコメントアウトトグル
  • Ctrl + Alt + - 選択範囲に基づいてセルを分割する (Split Cell)
  • Ctrl + Shift + K 現在行を削除（複数行選択時は複数行削除）
  • Ctrl + Shift + D 現在行（または選択中の複数行）を下へ複製
  • Ctrl + Shift + ↑ / ↓ 選択行 / 現在行を上下に移動（同一セル内）
  • Ctrl + B 選択文字列を強調表示（**太字**）
  • Ctrl + I 選択文字列を斜体表示（*イタリック*）
  • Ctrl + Alt + L 現在行をヘッダー下線から12行下の位置に移動

Command Mode (コマンドモード) - セル選択中

  • Enter 選択中のセルを編集する（Editモードへ移行）
  • J または ↓ 下のセルを選択
  • K または ↑ 上のセルを選択
  • H または ← 左のペインへ移動
  • L または → 右のペインへ移動
  • Ctrl + Shift + ↑ / ↓ 選択中のセルを上下に移動（順序変更）
  • A 選択しているセルの「上」に新しいセルを追加
  • B 選択しているセルの「下」に新しいセルを追加
  • D, D (Dを2回) 選択中のセルを削除
  • C 選択中のセルをコピー
  • X 選択中のセルをカット
  • V コピー/カットしたセルを下に貼り付け
  • Shift + V コピー/カットしたセルを上に貼り付け
  • Shift + クリック / 矢印キー 複数セルを選択状態にする
  • Shift + M 複数選択されたセルを全て結合
  • Z セル操作のUndo（元に戻す）
  • Shift + Z セル操作のRedo（やり直す）
  • Ctrl + A すべてのセルを選択
  • Ctrl + Alt + L 選択セルの上枠をヘッダー下線から2行下の位置に移動
  • G, G 先頭セルへ移動
  • [番号] + G, G 指定番号のセルを選択し画面中央へ移動 (例: 5gg)
  • Shift + G 末尾セルへ移動
  • Shift + Enter セルを実行（プレビュー）
  • Ctrl + \ 画面を垂直（左右）に分割（最大3ペイン）

Global Shortcuts (共通)

  • Ctrl + Shift + ← / H 左のタブへ切り替え
  • Ctrl + Shift + → / L 右のタブへ切り替え
  • Ctrl + N / Ctrl + Alt + N 新規ノートブック（タブ）を作成
  • Ctrl + Alt + W 現在のタブを閉じる
  • Ctrl + Alt + M 右側のペインを左隣へ統合 (マージ)
  • Ctrl + S ファイルを保存
  • Ctrl + Alt + S 名前をつけてファイルを保存
  • Ctrl + \ 垂直分割 (Split Vertically, 最大3ペイン)
  • Ctrl + C / X / V ファイル操作 (選択ファイルのコピー / カット / 貼り付け)
